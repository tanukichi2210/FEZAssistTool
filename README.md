# 主な機能

- 多重起動補助
- ウィンドウ移動
- INPUT.INI切り替え
- GLOBAL.INI書換
- 音量調整
- エンチャント自動合成
- ロイチケ自動交換
- Ring回収
- etc...

---

# インストール

1. ZIPをダウンロード
2. 任意の場所へ解凍
3. Handleフォルダ内の handle64.exe または handle64a.exe を一度だけ実行し、規約に同意してください。
4. config.txt を環境に合わせて設定してください。
5. FEZAssistTool.exe を管理者権限で起動してください。

---

# 必須設定

config.txt の以下は必ず設定してください。

- LauncherPath
- FEzero_ClientPath

その他は必要に応じて変更できます。
